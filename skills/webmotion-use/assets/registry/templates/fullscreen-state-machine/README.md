# Fullscreen State Machine

WebMotion E03 template for turn wheel or touch input into a small number of explicit full-screen states when ordinary document displacement would weaken the story.

## Interaction identity

The document remains fixed while a focusable internal scroller owns progress. State buttons can move between stops and the final state exposes an exit.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
