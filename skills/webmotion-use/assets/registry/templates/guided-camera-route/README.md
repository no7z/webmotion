# Guided Camera Route

WebMotion E05 template for guide readers through spatial evidence in a fixed order without turning the page into a free-roaming game.

## Interaction identity

Native document scroll moves a damped camera along a continuous route. Declared stops align copy, camera, and evidence while remaining reversible.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
