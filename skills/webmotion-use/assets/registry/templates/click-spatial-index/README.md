# Click Spatial Index

WebMotion E09 template for let readers browse hierarchical spaces directly when sequence is less important than location and comparison.

## Interaction identity

Click or keyboard selection chooses a floor and room. Selection updates model emphasis, camera framing, pins, and the DOM record in place.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
