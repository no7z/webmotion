# Editorial Media Rhythm

WebMotion E07 template for build a premium editorial information page when continuous 3d would distract from reading.

## Interaction identity

Ordinary document flow remains primary. Media and type enter through native scrolling; one embedded 3D figure answers a local question and then releases the reader.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
