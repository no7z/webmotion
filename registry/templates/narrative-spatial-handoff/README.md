# Narrative Spatial Handoff

WebMotion E06 template for build enough context through narrative progression, then let readers directly select places, records, or nodes.

## Interaction identity

Native scroll owns the story. After an explicit handoff, pointer and keyboard selection own the spatial index; further scrolling does not change selection.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
