# Spatial Product Document

WebMotion E08 template for use 3d to clarify one product structure without making every section depend on a persistent canvas.

## Interaction identity

Ordinary document flow. The hero object uses bounded ambient motion and one CTA scrolls to standard specifications.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
