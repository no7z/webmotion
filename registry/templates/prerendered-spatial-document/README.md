# Pre-rendered Spatial Document

WebMotion E10 template for deliver reliable spatial storytelling when realtime interaction adds cost but no additional information value.

## Interaction identity

Native document scrolling and ordinary image loading only. Media can be replaced by video, image sequences, or responsive pictures without a realtime scene.

## Adapter

The included react-media adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-media/src/template.config.js`.
