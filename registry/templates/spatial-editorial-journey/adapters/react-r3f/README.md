# React Three Fiber adapter

This adapter implements WebMotion `spatial-editorial-journey@0.1.0` with React, React Three Fiber, Three.js, Lenis, and Vite.

## Replace first

1. Update `src/content.js` with the target editorial subject and locale copy.
2. Put licensed replacement media in `public/images` and update `src/assets.config.js`.
3. Tune desktop and mobile paths together in `src/motion.config.js`.
4. Preserve the shared source-end/traverse-start keyframe.
5. Run the package QA checkpoints at both desktop and mobile sizes.

The included scene uses procedural terrain, river, forest, rain, and estuary particles. No external 3D model is required.
