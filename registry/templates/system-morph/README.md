# System Morph

WebMotion E01 template for explain how one product, material, or idea expands into a complete system without replacing the visual subject between chapters.

## Interaction identity

Native vertical document progress continuously controls subject scale, density, distribution, and camera distance. Reverse scrolling restores every intermediate composition.

## Adapter

The included react-r3f adapter uses fictional bilingual copy and original procedural visuals. Replace content in `adapters/react-r3f/src/template.config.js`.
