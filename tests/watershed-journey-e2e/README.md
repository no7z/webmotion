# Following the Current / 循流而行

一个原创的 WebMotion 环境空间旅程实验，用来验证类似长篇自然纪实网页的交互语法，而不是复制第三方品牌内容。

## 运行

```bash
npm install
npm run dev
```

本地入口：`http://localhost:4192/`

## 交互契约

- 单个固定全屏 Three.js / WebGL 场景由全局滚动进度连续驱动。
- Lenis 只负责滚动插值，不使用章节强制吸附。
- 源头章节把同一幅二维摄影纹理通过顶点位移、网格显现和相机抬升连续转换成 3D 地形。
- 雾林章节把纵向滚轮映射成四个视口宽的连续横向轨道，DOM 注释和 3D 相机同步向右穿越山体。
- 7 个章节在沉浸场景、摄影切片、坐标档案、编辑排版、点云雨场和浅色地理图版之间切换。
- 左侧路线进度和地图索引都能跳转到章节；地图打开时锁定背景滚动。
- 手机端重组阅读顺序、图片位置、字号和地图布局，不直接缩放桌面构图。
- `prefers-reduced-motion` 下关闭平滑滚动，并把 3D 状态直接映射到滚动进度。

## 技术

- React 19
- React Three Fiber / Three.js
- Lenis
- Vite
- 程序化地形、河道、点云森林、雨场和河口粒子
- 自定义 GLSL 图片到地形形变材质

## 内容与素材边界

页面只参考了目标网址公开可见的布局、滚动节奏和交互行为。概念、文案、标识、程序化 3D 和 `public/images/*.webp` 均为本项目原创或为本实验生成；未复制国家地理的图片、模型、品牌标识、文章或源代码。
